# Память и экономия токенов — реализация v8

> Исторические состояния версий сохранены ниже. Изменения после аудита issue #9 и актуальные границы проверки: [issue-9-fixes](issue-9-fixes.md). Старые лимиты и отсутствие функций не являются описанием текущей ветки.

Требования: Obsidian `Ilmar/Модели и экономия токенов.md`, `Ilmar/Чаты и память.md`. Это описание проверяемого среза, не второй Roadmap. Предыдущий аудит v7 обнаружил отправку полной истории без Compact; v8 меняет эту часть.

| Компонент | Реализация |
| --- | --- |
| Полная история | SQLite сохраняет исходные сообщения и ссылки на приватные оригиналы вложений. Compact их не изменяет. Миграция v1/v2/v3 → v4 добавляет таблицы без пересоздания истории. |
| Рабочая проекция | ContextEngine передаёт правила, активную capsule, последние сообщения дословно и ограниченные найденные фрагменты. Старые изображения после сжатия не перечитываются; оригиналы доступны в истории. |
| Compact | Автоматически при 80% локального окна с учётом резерва, вручную через меню чата. Выбранная модель, отдельная оплачиваемая операция в существующей очереди. Большой участок разбивается на ограниченные пакеты, не более 24. |
| Последние сообщения | 0–20 настраиваемых сообщений, граница сохраняет полные пары; текущий запрос всегда остаётся дословно. Если сам хвост/правила не помещаются, отправка останавливается с предложением изменить настройки в том же чате. Скрытой обрезки нет. |
| Capsule | Версии JSON goal/facts/decisions/progress/files/tests/errors/next/uncertain, в интерфейсе читаемые русские названия. Просмотр, повторное сжатие, выбор и удаление версии без удаления исходников. Формат/размер/завершение проверяются до активации. Проверка не гарантирует семантическую полноту сводки. |
| Неизменяемые правила | Отдельная таблица и редактор чата. Пользователь задаёт правила/утверждённые решения явно; они передаются дословно и не переписываются суммаризатором. Автоматического распознавания всех утверждённых решений из старой переписки нет. |
| Контрольная точка | Состояние Compact, fingerprint источников/настроек/модели, номер пакета и рабочая сводка. Явный повтор возобновляет пригодный checkpoint. Оплаченный ответ пакета и usage сохраняются одной транзакцией; сохранённый ответ повторно не покупается. Перезапуск сам не запускает платные запросы. Это checkpoint сжатия, не полный runtime произвольной агентной задачи. |
| Бюджет | Считаются сообщения, правила, capsule, извлечённый текст/изображения, retrieval, схемы и весь текущий цикл инструментов. Модельное окно ограничивает локальное. Последовательность tool_calls/results не обрезается. Резерв вывода передаётся max_tokens/max_completion_tokens только поддерживаемому адаптеру. |
| Локальные лимиты задачи | Проверка токенов/опционального USD перед каждым модельным вызовом, включая Compact. После ответа — уточнение по usage; без usage сохраняется консервативный резерв. Бюджет действует на одну явную отправку/сжатие. Изображения при USD-лимите без денежной оценки отклоняются. Денежная оценка требует тарифов текста/запроса и ограниченного вывода. Квота провайдера нужна для жёсткого лимита счёта. |
| Prompt caching | Стабильный префикс не содержит дат/ID запроса. OpenAI использует автоматический caching API. Явный ephemeral cache добавляется только OpenRouter/Anthropic, при оценке длины ≥2048 и известных тарифах: запись + 2 чтения дешевле 3 обычных входов; стандартный TTL 5 минут. Для остальных API поля не добавляются. Будущие попадания и тарификация не гарантированы; факт только cached_tokens. |
| Учёт | Фактический usage каждого вызова, отдельное число/стоимость Compact, кэшированные токены и оценка сокращения входа. Неизвестные значения не заменяются нулём. Оценка сокращения не равна чистой денежной экономии; Compact тоже оплачивается. |
| Поиск | Локальный SQLite FTS4 с триггерами, старые строки индексируются на worker при первом поиске. До трёх кратких фрагментов из покрытой сводкой истории добавляются при совпадении слов текущего запроса, если остаётся бюджет. Это не гарантия восстановления всех фактов и не векторный RAG. |
| Метаданные | RegistrySnapshot и capabilities декодируются один раз на сохранённую версию; изменение raw-данных инвалидирует кэш. Экран озвучки загружает аудиомодели на worker, не на каждый ввод символа. |

Оценка токенов по UTF-8 и запасу на изображения не является точным токенизатором каждой модели. Реальные значения зависят от API; окно и резервы можно изменить в настройках. Синтетические тесты сравнивают полную/сокращённую проекцию, сохранность последних сообщений, правила и контракт usage. Реальное сравнение API-расходов/качества сводки на одинаковых диалогах остаётся телефонной проверкой: фиксировать вход/выход/cache/стоимость до и после, отдельно стоимость Compact и потери фактов.

За пределами среза: универсальные провайдерные адаптеры кэширования, TTL-кэш инструментальных чтений/индекс репозитория, ленивый search→describe→execute для сотен инструментов, отдельное хранилище полных больших результатов инструментов, измерение чистой экономии в USD по всем тарифам, полноценные checkpoints агентных задач. Production-исполнители GitHub/SSH/Shell/браузера ещё не установлены; эти функции не подменяются заглушками.
