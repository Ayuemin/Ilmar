## Code findings to reproduce

* Registration: retrieval schemas added once to authorized agent tools; Fetch authorization inherited, no catalogue duplication found. Search schema accepts query/limit but no document_id. Extra properties currently produce INVALID_ARGUMENTS. Actual model misuse requires JSONL.
* AgentLoopRunner catches JSON/argument exceptions from execute, but document store/section lookup uses IllegalStateException. Such lookup errors abort a run instead of becoming recoverable tool results. Permission checks before execution must keep fail-closed task termination.
* Existing repeat guard fingerprints output as well as canonical arguments, requires two repeated series, and can be disabled. Changing error messages or intervening calls evade its identical-failure detection. Default unchanged errors can cost six calls before stopping. No automatic model retry exists in this loop; additional rounds are generated by the model after tool results.
* Initial retrieval truncates the combined latest user request at 1000 characters and ranks all topics together (24 lexical terms maximum). No per-question coverage/fairness exists.
* DocumentSession tracks delivered blocks and supports exact repeat/expansion, but generic ToolHistoryProjection may remove original quotes while keeping the sent ledger. Empty search conflates already-delivered with no-match. Source survives in run RAM; original tool traces persist separately.
* Every generate receives accumulated projected tool history. ContextEngine projects it again to min(trace_tokens, context/3). Context Compact is independent and no global change is justified.
* HTTPS/SSRF validation, permission checks after IO, session RAM quotas/TTL/close and Legacy extraction must remain intact.
