## Основания из ТЗ Codex

- `docs/continuous-context-and-diagnostics.md`: оригиналы истории и вложений сохраняются; группы вызов/результат должны оставаться целыми; tool traces доступны через `read_file(trace:<id>)`; ошибки, отмена и ограничения должны быть явными; SQLite v4→v5→v6 без потери данных.
- `docs/android-tools-mvp.md`: разрешения проверяются непосредственно перед вызовом; созданные файлы и планы сохраняются; `ask_user` останавливает задачу; native tools не являются песочницей произвольного кода.
- Прежние регрессии, телефонная приёмка и ограничения документированы там же; не подменять её unit-тестами.
