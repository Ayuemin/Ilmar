Architectural reference: Agora build-proot.sh at 3e7b0c8c89d591c3cd58a4bc6824861223576c1d. Ilmar uses its own Kotlin runtime/UI and build orchestration.
Ilmar patches PRoot's cross-compilation probes, a missing string.h include and the loader symbol parser.
The exact original sources, patched sources, launcher and build script are included in the
ilmar-alpine-corresponding-source artifact alongside each APK in GitHub Actions.
https://github.com/Ayuemin/Ilmar/actions
Build instructions and limitations: docs/github-and-alpine.md in that repository.

Alpine minirootfs and packages are downloaded separately from dl-cdn.alpinelinux.org.
Their package licences and upstream sources are described at https://pkgs.alpinelinux.org/.
Alpine is Linux userspace running with the application's UID, not a security sandbox.
